## How to Run the Project Locally

Follow these steps to set up and run **Lumin** on your local machine.

### Step 1: Clone the Repository
```bash
git clone https://github.com/Kashif581/Lumin.git
```

### Step 2: Navigate to the Project Directory
```bash
cd Lumin
```

### Step 3: Create a Python Virtual Environment
```bash
python -m venv venv
```

### Step 4: Activate the Virtual Environment

**Windows:**
```bash
venv\Scripts\activate
```
### Step 5: Install Backend Dependencies
```bash
pip install -r requirements.txt
```

### Step 6: Navigate to the Frontend Directory
```bash
cd frontend
```

### Step 7: Install Frontend Dependencies
```bash
npm install
```

### Step 8: Build the Frontend
```bash
npm run build
```

### Step 9: Return to the Root Directory
```bash
cd ..
```

### Step 10: Run the Application
```bash
python server.py
```

🎉 **Congratulations!** Your Lumin application is now running locally.
